# AI 编码审查清单

## 需求与范围

- [ ] 实现直接对应已确认目标。
- [ ] 未引入未经请求的重构、依赖或行为变化。
- [ ] 非目标仍然成立。

## 正确性与测试

- [ ] 正常路径和关键边界已验证。
- [ ] 错误处理符合现有约定。
- [ ] 类型检查、测试、构建或手动验收已执行，并记录结果。

## 安全与数据

- [ ] 没有写入密钥、账号、个人信息、客户资料或生产数据。
- [ ] 权限、输入校验和敏感操作边界没有被扩大。

## 可维护性

- [ ] 命名、结构和依赖符合当前仓库惯例。
- [ ] 复杂逻辑有必要的测试或简洁说明。
- [ ] 修改范围足够小，后续可回滚和定位。
